# 2. Функции маркетплейса

## 2.1. Главная страница

Состав:
- логотип QaitaBuild;
- навигационное меню;
- кнопки «Войти» / «Регистрация»;
- краткое описание проекта;
- большой поисковый блок для стройматериалов;
- кнопка **«Найти материалы»**;
- кнопка **«Подобрать материалы для моего проекта»** (ведёт в AI Project Reuse Planner);
- блок популярных категорий;
- блок последних объявлений (из базы, не моки);
- блок «Как работает QaitaBuild»;
- блок о возможностях ИИ;
- футер с контактами и ссылками.

Стиль: современный, минималистичный, понятный; связан со строительством и экологией. Подробнее в [07-design.md](07-design.md).

## 2.2. Регистрация и авторизация

Через **Supabase Authentication**:
- регистрация по email и паролю;
- вход;
- выход;
- восстановление пароля.

После регистрации у пользователя появляется личный кабинет (запись в `profiles`).

## 2.3. Каталог

### Что показано в карточке
Фото · название · категория · цена в ₸ · количество · состояние · город · краткое описание · имя продавца.

### Категории
1. Кирпич и блоки
2. Древесина и пиломатериалы
3. Металл
4. Плитка и керамогранит
5. Двери и окна
6. Сантехника
7. Электрика
8. Кровельные материалы
9. Отделочные материалы
10. Другие материалы

**[предложение]** Слаги для БД: `bricks_blocks`, `wood_lumber`, `metal`, `tiles`, `doors_windows`, `plumbing`, `electrical`, `roofing`, `finishing`, `other`.

### Функции
- Поиск по названию.
- Фильтры: категория, диапазон цены, состояние, город.
- Сортировка: по цене, по дате добавления.
- Все цены в тенге (₸).

## 2.4. Размещение объявления

Поля формы:

| Поле | Обязательное **[предложение]** |
|---|---|
| Название материала | да |
| Категория | да |
| Фотографии | да, минимум 1 |
| Количество | да |
| Единица измерения | да |
| Состояние | да |
| Цена (₸) | да |
| Город | да |
| Описание | нет |
| Контактные данные | да |

Поток:
1. Пользователь заполняет форму и загружает фото.
2. Нажимает **«AI-анализ материала»**.
3. ИИ предлагает тип материала, видимые дефекты, предварительное состояние, способы восстановления и варианты повторного использования.
4. Пользователь проверяет и правит предложения ИИ.
5. После подтверждения объявление сохраняется и появляется в каталоге.

Перед сохранением система проверяет обязательные поля.

**[предложение]** Значения состояния: «Новое (остаток)», «Отличное», «Хорошее», «Удовлетворительное», «Требует восстановления».
**[предложение]** Единицы измерения: шт, м², м³, м, пог. м, кг, т, упак., комплект.

## 2.5. Личный кабинет

- Имя, email, город.
- Мои объявления (открыть, редактировать, удалить).
- Избранное.
- История AI-анализов.
- Цифровые паспорта материалов.
- Настройки профиля.
- Кнопка выхода.

## 2.6. Связь с продавцом

- В карточке есть кнопка **«Связаться с продавцом»**.
- В MVP она показывает контакты продавца или ведёт во внешний мессенджер / звонок.
- Внутренний чат в первую версию **не входит**.

**[предложение]** Показывать контакты только авторизованным пользователям, чтобы их не собирали боты.
