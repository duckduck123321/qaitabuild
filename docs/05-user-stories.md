## EPIC 1. Регистрация и авторизация

### US-01. Регистрация
*Как пользователь, я хочу зарегистрироваться, чтобы размещать объявления и пользоваться AI-функциями.*
- [ ] Регистрация через email и пароль.
- [ ] Система проверяет корректность данных.
- [ ] После регистрации доступен личный кабинет.

### US-02. Авторизация
*Как зарегистрированный пользователь, я хочу входить в аккаунт, чтобы управлять объявлениями и анализами.*
- [ ] Вход по email и паролю.
- [ ] При неверных данных показывается сообщение об ошибке.
- [ ] Можно выйти из аккаунта.

## EPIC 2. Каталог

### US-03. Просмотр каталога
*Как покупатель, я хочу просматривать материалы, чтобы находить подходящие.*
- [ ] Отображаются карточки материалов.
- [ ] На карточке есть фото, название, цена, город.
- [ ] Можно открыть подробную страницу объявления.

### US-04. Поиск и фильтрация
*Как покупатель, я хочу фильтровать по категориям, цене и городу, чтобы быстрее находить нужное.*
- [ ] Поиск по названию.
- [ ] Выбор категории.
- [ ] Диапазон цены.
- [ ] Фильтр по городу.
- [ ] Сортировка.

## EPIC 3. Размещение объявлений

### US-05. Создание объявления
*Как продавец, я хочу размещать оставшиеся материалы, чтобы найти покупателей.*
- [ ] Есть форма создания.
- [ ] Можно добавить фото.
- [ ] Можно указать цену, количество, состояние.
- [ ] После подтверждения объявление сохраняется в БД.
- [ ] Объявление появляется в каталоге.

### US-06. Редактирование объявления
*Как продавец, я хочу редактировать свои объявления, чтобы обновлять информацию.*
- [ ] Можно изменить описание и цену.
- [ ] Можно заменить фото.
- [ ] Можно удалить своё объявление.
- [ ] Нельзя редактировать чужие объявления (проверяется RLS).

## EPIC 4. AI Material Inspector

### US-07. Анализ фотографии
*Как продавец, я хочу загрузить фото материала и получить предварительный анализ, чтобы лучше представить материал покупателю.*
- [ ] Можно загрузить фото.
- [ ] ИИ анализирует изображение.
- [ ] Определяется предполагаемый тип материала.
- [ ] Выводятся видимые дефекты.
- [ ] Выводятся рекомендации.
- [ ] Результат можно использовать при создании объявления.

## EPIC 5. AI Project Reuse Planner

### US-08. Подбор материалов под проект
*Как покупатель, я хочу описать проект обычными словами, чтобы ИИ предложил подходящие вторичные материалы.*
- [ ] Есть поле для описания проекта.
- [ ] ИИ анализирует описание.
- [ ] ИИ выделяет нужные материалы.
- [ ] ИИ предлагает альтернативы для повторного использования.
- [ ] Система ищет реальные объявления в БД.
- [ ] Показываются только существующие подходящие объявления.
- [ ] Если подходящих нет, система об этом сообщает.

## EPIC 6. AI Recovery Planner

### US-09. Рекомендации по восстановлению
*Как владелец материалов, я хочу получить рекомендации по восстановлению, чтобы понять, можно ли их использовать повторно.*
- [ ] Можно выбрать материал или загрузить фото.
- [ ] ИИ анализирует видимые проблемы.
- [ ] Предлагаются очистка и восстановление.
- [ ] Предлагаются варианты повторного использования.
- [ ] Есть предупреждение о дополнительных проверках.

## EPIC 7. AI Pre-Demolition Scanner

### US-10. Анализ помещения перед демонтажем
*Как человек, планирующий ремонт или демонтаж, я хочу загрузить фото помещения, чтобы узнать, что можно сохранить.*
- [ ] Можно загрузить фото помещения.
- [ ] ИИ анализирует видимые элементы.
- [ ] Составляется предварительный список.
- [ ] Для каждого элемента есть варианты повторного использования.
- [ ] Пользователь может выбрать элементы.
- [ ] Можно перейти к созданию объявления.

## EPIC 8. AI Material Passport

### US-11. Цифровой паспорт
*Как продавец, я хочу получить цифровой паспорт материала, чтобы покупатели видели его характеристики и состояние.*
- [ ] Паспорт строится на AI-анализе и данных продавца.
- [ ] Отображаются название, категория, фото.
- [ ] Отображаются дефекты и рекомендации.
- [ ] Информацию можно редактировать.
- [ ] Данные пользователя отделены от предположений ИИ.
- [ ] Паспорт сохраняется в БД.

## EPIC 9. Личный кабинет

### US-12. Мои объявления
*Как продавец, я хочу видеть все свои объявления в кабинете, чтобы управлять ими.*
- [ ] Отображаются объявления текущего пользователя.
- [ ] Каждое можно открыть.
- [ ] Можно редактировать и удалять.

### US-13. Избранное
*Как покупатель, я хочу добавлять материалы в избранное, чтобы не потерять их.*
- [ ] Есть кнопка «В избранное».
- [ ] Избранное сохраняется.
- [ ] Избранное видно в кабинете.
- [ ] Можно удалить из избранного.
