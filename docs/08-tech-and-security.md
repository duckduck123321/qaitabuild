# 8. Технологии и безопасность

## Стек

| Слой | Технология |
|---|---|
| UI | React, TypeScript, Tailwind CSS, shadcn/ui |
| Генерация интерфейса | Lovable |
| Backend | Supabase |
| База данных | PostgreSQL (Supabase) |
| Авторизация | Supabase Authentication |
| Файлы | Supabase Storage |
| Серверная логика AI | Supabase Edge Functions |
| Секреты | Supabase Secrets |
| ИИ | Мультимодальная модель через API, 5 отдельных промптов, ответ в JSON |

Конкретная AI-модель и провайдер в PRD не выбраны, см. [open-questions.md](open-questions.md).

## [предложение] Архитектура AI-вызова

```
React (браузер)
   │ supabase.functions.invoke('ai-inspector', { imagePath })
   ▼
Edge Function  ── читает API_KEY из Secrets
   │  ├─ берёт фото из Storage
   │  ├─ вызывает модель с системным промптом функции
   │  ├─ валидирует JSON по схеме
   │  ├─ (Reuse Planner) ищет объявления в listings
   │  └─ пишет запись в ai_analyses
   ▼
React показывает карточку результата
```

Одна Edge Function на каждую AI-функцию, либо одна `ai` с параметром `type`.

## Нефункциональные требования

1. Корректная работа на компьютерах, планшетах и смартфонах; адаптивный интерфейс.
2. Понятные сообщения об успехе и ошибке для всех основных действий.
3. Фото загружаются в Supabase Storage.
4. Данные пользователей защищены (RLS).
5. **API-ключи никогда не попадают в клиентский код.**
6. AI-ответы обрабатываются в структурированном формате.
7. Если AI-сервис недоступен, пользователь получает понятное сообщение.
8. Обязательные поля проверяются перед сохранением объявления.
9. ИИ не выдумывает наличие материалов, цены и характеристики.

## Чек-лист безопасности

- [ ] RLS включён на всех таблицах, политики проверены под чужим аккаунтом.
- [ ] Во фронтенде только `anon` key; `service_role` и AI-ключ лежат только в Secrets.
- [ ] Storage: запись только в свою папку.
- [ ] **[предложение]** Ограничение размера и типа загружаемых фото (например, ≤10 МБ, jpg/png/webp).
- [ ] **[предложение]** Лимит AI-запросов на пользователя, чтобы не сжечь бюджет API.
- [ ] **[предложение]** Контакты продавца видны только авторизованным.
