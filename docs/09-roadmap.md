# 9. Объём MVP и этапы

## ✅ Демо-минимум (что реально делаем)

Проект студенческий, поэтому план ниже важнее полного списка из PRD.

**Обязательно для демо**
1. Главная страница с поиском, категориями и последними объявлениями.
2. Регистрация и вход по email (без подтверждения почты).
3. Каталог: поиск, фильтры по категории, городу и цене, сортировка.
4. Страница объявления с кнопкой «Связаться».
5. Создание объявления с фото.
6. **AI Project Reuse Planner** с поиском по реальным объявлениям — главная фишка демо.
7. **AI Material Inspector** при создании объявления. Его ответ сразу сохраняется как **Material Passport** и показывается на странице объявления.
8. Кабинет: мои объявления (редактировать и удалить) и избранное.
9. 25–40 seed-объявлений во всех категориях с фото.

**Если останется время**
10. AI Recovery Planner.
11. AI Pre-Demolition Scanner.
12. История AI-анализов в кабинете.

**Не делаем:** админку, жалобы, i18n, лимиты, роли специалистов, чат, оплату, доставку, отзывы.

### Порядок работы
1. Интерфейс в Lovable на тестовых данных.
2. Supabase: таблицы, авторизация, bucket, seed.
3. Подключить к Supabase каталог, объявления и кабинет.
4. Reuse Planner.
5. Inspector и Passport.
6. Опциональные AI-функции.
7. Прогон демо-сценариев на телефоне и ноутбуке.

## Этапы разработки (по PRD)

Каждый этап проверяется до перехода к следующему.

| Этап | Содержание |
|---|---|
| **1. Интерфейс** | Главная, навигация, каталог, карточки, страница объявления, страницы AI-функций |
| **2. Supabase** | БД, авторизация, таблицы, Storage, права доступа (RLS) |
| **3. Маркетплейс** | Регистрация, вход, кабинет, создание и редактирование объявлений, каталог, поиск и фильтры |
| **4. AI** | По очереди: Inspector → Recovery → Passport → Reuse Planner → Pre-Demolition |
| **5. Тестирование** | Регистрация, объявления, фото, каталог, все 5 AI, мобильная версия, ошибки, безопасность |
| **6. Демо** | Тестовые объявления, демо-фото, примеры AI-запросов, прогон всех сценариев |

## Альтернативный порядок (рекомендация из того же документа)

1. Основа: главная, навигация, регистрация, Supabase
2. Маркетплейс: каталог, объявления, фото, фильтры, кабинет
3. **Первый AI-модуль: Project Reuse Planner** с поиском реальных объявлений
4. Material Inspector и Recovery Planner
5. Material Passport
6. Pre-Demolition Scanner
7. Тестирование и демо

> Главная мысль обоих вариантов: **сначала рабочий маркетплейс, потом ИИ**. Иначе ИИ нечего анализировать и не в чем искать.
