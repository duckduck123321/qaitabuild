# 6. Пользовательские сценарии

## Сценарий 1. Продажа материала

```
Вход / регистрация
  → «Разместить объявление»
  → загрузка фото
  → AI Material Inspector (тип, дефекты, состояние)
  → AI Recovery Planner (восстановление, применение)
  → создаётся AI Material Passport
  → продавец проверяет и дополняет
  → публикация
  → объявление в каталоге
```

Проверить в демо: объявление видно в каталоге и в «Моих объявлениях», паспорт открывается со страницы объявления.

## Сценарий 2. Поиск материала для проекта

```
AI Project Reuse Planner
  → описание проекта текстом
  → ИИ выделяет материалы и альтернативы
  → поиск по реальным объявлениям в Supabase
  → список подходящих объявлений (или честное «ничего не найдено»)
  → карточка объявления
  → «Связаться с продавцом»
```

## Сценарий 3. Подготовка к демонтажу

```
AI Pre-Demolition Scanner
  → фото помещения
  → ИИ находит видимые элементы
  → список того, что потенциально можно сохранить
  → пользователь отмечает элементы
  → рекомендации по повторному использованию
  → (опционально) создание объявлений
```

## [предложение] Карта страниц

| Маршрут | Страница | Доступ |
|---|---|---|
| `/` | Главная | все |
| `/catalog` | Каталог с фильтрами | все |
| `/listing/:id` | Карточка объявления + паспорт | все |
| `/auth/login`, `/auth/register`, `/auth/reset` | Авторизация | гости |
| `/listing/new`, `/listing/:id/edit` | Форма объявления | авторизованные |
| `/ai/inspector` | Material Inspector | авторизованные |
| `/ai/project-planner` | Project Reuse Planner | все (сохранение — авторизованным) |
| `/ai/recovery` | Recovery Planner | авторизованные |
| `/ai/pre-demolition` | Pre-Demolition Scanner | авторизованные |
| `/passport/:id` | Цифровой паспорт | все |
| `/account` | Кабинет: объявления, избранное, анализы, паспорта, настройки | авторизованные |
| `/admin` | Модерация (если войдёт в MVP) | админ |
