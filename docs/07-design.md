# 7. Дизайн и UX/UI

## Настроение
Современно, минималистично, профессионально. Ассоциации: архитектура, строительство, экология, повторное использование, технологии.

## Палитра

| Роль | Цвет | HEX |
|---|---|---|
| Основной (primary) | Тёмно-зелёный | `#244D3C` |
| Вторичный | Светло-зелёный | `#A8C7A0` |
| Фон | Светлый | `#F7F8F5` |
| Поверхности, карточки | Белый | `#FFFFFF` |
| Текст | Тёмно-серый | `#292D2B` |

Акцентные цвета выделяют AI-функции и интерактивные элементы. Для AI выбран акцент `#E0A33B` (тёплый янтарный), см. [open-questions.md](open-questions.md).

**[предложение]** Токены для Tailwind / shadcn:
```css
:root {
  --primary: #244D3C;
  --secondary: #A8C7A0;
  --background: #F7F8F5;
  --card: #FFFFFF;
  --foreground: #292D2B;
}
```

## Типографика
Inter или аналогичный современный читаемый шрифт (нужна кириллица, позже казахские буквы: ә ғ қ ң ө ұ ү һ і; у Inter они есть).

## Интерфейс
- Скруглённые карточки.
- Простые и понятные кнопки.
- Качественные фото материалов.
- Минималистичные иконки.
- Понятные формы.
- Адаптивная сетка (десктоп, планшет, смартфон).
- Не перегружать страницы текстом и декором.

## Визуальные правила для AI
- Результаты ИИ показываются структурированными карточками.
- Предположения ИИ визуально отличаются от данных пользователя и подтверждённых данных (метки 🧑 / 🤖 / ✅ или бейджи).
- У каждого AI-результата есть дисклеймер о предварительном характере анализа.
- У каждого AI-запроса есть состояния загрузки и ошибки.
