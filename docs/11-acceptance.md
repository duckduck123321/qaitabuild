# 11. Критерии готовности MVP

MVP готов к демонстрации, если:

- [ ] Пользователь может зарегистрироваться и войти.
- [ ] Продавец может разместить стройматериал.
- [ ] Фотографии сохраняются (Supabase Storage).
- [ ] Объявления сохраняются в Supabase.
- [ ] Покупатель может искать и фильтровать материалы.
- [ ] Можно открыть карточку материала.
- [ ] AI Material Inspector возвращает структурированный анализ фото.
- [ ] AI Recovery Planner выдаёт рекомендации.
- [ ] AI Material Passport создаёт и сохраняет паспорт.
- [ ] AI Project Reuse Planner разбирает описание проекта и находит **реальные** объявления.
- [ ] AI Pre-Demolition Scanner составляет предварительный список элементов помещения.
- [ ] Личный кабинет показывает данные пользователя.
- [ ] Сайт работает на компьютере и смартфоне.
- [ ] Основные действия проходят без критических ошибок.

## План тестирования (этап 5)

| Что проверить | Как **[предложение]** |
|---|---|
| Регистрация | Новый email → письмо → вход → кабинет |
| Объявления | Создать, отредактировать, удалить; попытаться изменить чужое (должно не получиться) |
| Фото | Загрузить несколько; заменить; проверить в Storage |
| Каталог | Каждый фильтр по отдельности и в комбинации; сортировки |
| 5 AI-функций | По 2–3 подготовленных примера на функцию; плюс случай «ничего не найдено» для Reuse Planner |
| Мобильная версия | Ширина 375 px: все страницы без горизонтального скролла |
| Ошибки | Отключить AI-ключ: должно появиться понятное сообщение |
| Безопасность | Запрос к таблицам анонимом и под чужим аккаунтом |
