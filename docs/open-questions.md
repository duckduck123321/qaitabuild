Проект студенческий, его задача — показать демо. Поэтому каждый вопрос решён **самым простым рабочим вариантом**. Если команда захочет иначе, поправьте ответ здесь.

|---|---|---|
| 1 | Порядок AI-модулей | Сначала **Project Reuse Planner** (самый эффектный на демо), потом Inspector, затем Passport (собирается из ответа Inspector), Recovery, Pre-Demolition. |
| 2 | Админка | **Не делаем.** Модерация при необходимости — руками в Supabase Table Editor. |
| 3 | Жалобы | **Не делаем.** |

| 5 | Города | Фиксированный список: Алматы, Астана, Шымкент, Караганда, Актобе, Павлодар, Усть-Каменогорск, Атырау, Другой. |

| 17 | Юридические тексты | Не нужны. В футере короткая строка «Учебный проект». |

## Упрощения относительно PRD
- **RLS:** базовые политики «читают все, меняет только владелец» для `listings` и `listing_images`; «только своё» для `favorites`, `ai_analyses`, `project_requests`. Отдельных view для телефона нет.
- **Storage:** один публичный bucket `images`.
- **i18n:** не настраиваем. Тексты пишем на русском прямо в компонентах.
- **История AI-анализов в кабинете:** по желанию, если останется время.
- **Восстановление пароля:** стандартное письмо Supabase, без своей страницы оформления.
