# Глоссарий

| Термин | Значение |
|---|---|
| **QaitaBuild** | Название продукта («qaita» по-казахски значит «снова, повторно»). |
| **MVP** | Минимальная рабочая версия для демонстрации. |
| **PRD** | Product Requirements Document — документ требований к продукту. |
| **User Story** | Короткое описание того, что хочет пользователь и зачем, с критериями приёмки. |
| **Epic** | Группа связанных User Stories. |
| **Объявление (listing)** | Предложение о продаже материала в каталоге. |
| **Цифровой паспорт материала** | Структурированная карточка с характеристиками, состоянием и рекомендациями. Не сертификат. |
| **Material Inspector** | AI-анализ материала по фото. |
| **Project Reuse Planner** | AI-подбор вторичных материалов под проект с поиском реальных объявлений. |
| **Recovery Planner** | AI-рекомендации по очистке, восстановлению и повторному использованию. |
| **Pre-Demolition Scanner** | AI-анализ фото помещения: что можно сохранить перед демонтажем. |
| **Supabase** | Облачный backend: база Postgres, авторизация, хранилище файлов, серверные функции. |
| **RLS** | Row Level Security — правила Postgres, кто какие строки может читать и менять. |
| **Edge Function** | Серверная функция Supabase; в ней лежат AI-ключи и идут вызовы модели. |
| **Supabase Secrets** | Хранилище секретов (API-ключей) для Edge Functions. |
| **Storage** | Хранилище файлов Supabase (фото материалов). |
| **Lovable** | Сервис, генерирующий React-интерфейс по текстовому описанию. |
| **shadcn/ui** | Набор готовых UI-компонентов для React + Tailwind. |
| **Несущая конструкция** | Элемент здания, который держит нагрузку. ИИ не может оценивать пригодность для таких конструкций. |
