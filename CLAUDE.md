## Состояние кода
- Этап 1 готов: Vite + React + TS + Tailwind (без Lovable, локально). Запуск: `npm run dev`.
- Все данные идут через `src/lib/api.ts`. Сейчас это демо-бэкенд на localStorage с данными из `src/data/seed.ts`. При подключении Supabase меняется только этот файл, страницы не трогаем.
- UI-компоненты: `src/components/ui.tsx` (свои, в стиле shadcn). Цвета — в `tailwind.config.js` (`primary`, `sage`, `ai`, `ink`, `bg`, `line`).
- Страницы AI сейчас без модели: кнопки запуска отключены, на странице есть пометка «AI ещё не подключён».

## Стек
React + TypeScript + Tailwind + shadcn/ui (Lovable) · Supabase (Postgres, Auth, Storage, Edge Functions, Secrets) · мультимодальная AI-модель через Edge Functions, ответы в JSON.

## Правила (обязательно)
1. Работать поэтапно; не генерировать весь проект за раз. Проверять каждый этап.
2. Порядок: интерфейс → Supabase → маркетплейс → AI по одной функции.
3. Никаких фиктивных данных вместо БД в готовых функциях. Никаких пустых кнопок.
4. Секретные ключи — только в Supabase Secrets / Edge Functions, никогда во фронтенде.
5. Не ломать рабочие функции при добавлении новых.
6. Нереализованное — честно помечать «недоступно», не имитировать.
7. ИИ не выдумывает материалы, цены, характеристики; не гарантирует прочность/безопасность по фото; Reuse Planner показывает только реальные объявления из БД.
8. Перед изменением схемы БД — объяснить, какие таблицы/связи меняются.
9. Если нужен ключ или внешний сервис — сказать и пошагово объяснить, как подключить.
