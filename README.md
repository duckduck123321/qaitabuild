# QaitaBuild

Учебный проект: маркетплейс стройматериалов для повторного использования с AI-инструментами.
Требования и решения по проекту — в [docs/](docs/README.md). Отчёт (AI-модель, промты) — в [ОТЧЕТ.md](ОТЧЕТ.md).

## Как запустить

Нужен Node.js 18 или новее.

```bash
npm install
npm run dev
```

Откройте http://localhost:5173

## Сайт в интернете

**https://qaitabuild.vercel.app** — хостинг Vercel (проект `qaitabuild`). Адрес Supabase, ключ и имя AI-функции уже сохранены в настройках проекта на Vercel.

Как обновить сайт после изменений в коде:

```bash
npm run deploy
```

Перед первой публикацией с нового компьютера нужно войти в Vercel: `npx vercel login`.

## AI (Gemini)

- Edge Function в Supabase с адресом `quick-processor`, её код лежит в `supabase/functions/ai/index.ts`. Чтобы обновить функцию, вставьте новый код в редактор Supabase и нажмите Deploy.
- Ключ хранится в Supabase → Edge Functions → Secrets → `GEMINI_API_KEY`. Это тот же ключ, что у телеграм-бота.
- Модели можно поменять секретом `GEMINI_MODEL`: перечислите их через запятую, функция пробует по очереди.
- Проверка JWT у функции выключена, поэтому AI работает и у гостей.

## Supabase

Сайт работает с Supabase, если есть файл `.env.local` (образец — `.env.example`). Без него сайт включает демо-режим, и данные хранятся в браузере.

Настройка нового проекта Supabase с нуля:
1. Создайте проект на supabase.com. В **Project Settings → API** скопируйте Project URL и anon/publishable key в `.env.local`.
2. Откройте **SQL Editor**, вставьте содержимое `supabase/setup.sql` и нажмите **Run**. Файл создаёт таблицы, права доступа, хранилище фото и тестовые данные.
3. В **Authentication → Sign In / Providers**:
   - включите провайдер **Email**;
   - выключите **Confirm email**;
   - нажмите **Save**.

Чтобы обновить тестовые данные после правки `src/data/seed.ts`:
1. Выполните `node scripts/gen-seed.ts`.
2. Запустите `supabase/reseed.sql` в SQL Editor.

Копируя SQL через терминал, используйте UTF-8 (`LC_ALL=en_US.UTF-8 pbcopy`), иначе русский текст испортится.

## Что работает

- Главная, каталог с поиском, фильтрами и сортировкой, страница объявления, «Связаться с продавцом» (телефон и WhatsApp).
- Регистрация и вход, личный кабинет: мои объявления, избранное, профиль.
- Создание, редактирование и удаление объявлений с фото (до 5 шт).
- 31 тестовое объявление, у части из них есть пример цифрового паспорта.
- AI: подбор под проект (по реальным объявлениям), анализ фото с цифровым паспортом, план восстановления, сканер перед демонтажем, история анализов в кабинете.
- 30 из 31 тестового объявления с фото с Unsplash (бесплатная лицензия).

**Демо-режим** (без `.env.local`): данные хранятся в браузере, это `src/lib/backend-local.ts`.
У каждого браузера свои данные. Кнопка «Сбросить демо-данные» в футере возвращает всё к исходному виду.

## Структура

```
src/
  lib/api.ts         — все операции с данными (сейчас демо, потом Supabase)
  lib/auth.tsx       — текущий пользователь, защита страниц
  lib/constants.ts   — категории, города, состояния, единицы
  data/seed.ts       — тестовые объявления
  components/        — Layout, карточки, UI-элементы
  pages/             — страницы сайта
  pages/ai/          — страницы AI-инструментов
```
